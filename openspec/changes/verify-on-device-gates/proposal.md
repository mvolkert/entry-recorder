# Proposal

## Why

Many capabilities are build/test/lint-green but still owe an on-device or live-server confirmation (the old
Phase G gates). Under the verification convention, compile-green is not done, so these are tracked here
rather than silently marked complete in the specs.

## What Changes

- No behaviour/spec change — this is the acceptance checklist for already-implemented features.

## Capabilities

None. `skip_specs: true`.

## Impact

- Gate owners' hardware: Verso camera, Fritz!Box/PBX SIP, live Python server, Android 15/16 edge-to-edge,
  real-data Room upgrades.
